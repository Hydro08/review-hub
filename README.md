## Tech Stack

- React, Node.js, Tailwind

## Features

- User Registration (Sign Up)
- User Authentication (Login)
- OTP Verification for Sign Up
- Contact Form (Email integration using EmailJS)
- Dark / Light Mode Theme Toggle
- Responsive UI

## Planned Features

- Create Decks
- Add Flashcards
- Edit / Delete Decks and Flashcards
- Study Mode
- Custom Theme Settings (users can choose their preferred dark/light colors)
- Chat System (if budget allows)
